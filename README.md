# admingamb

The Gamb admin dashboard: Next.js 16, Tailwind, shadcn/ui, TanStack Query, Recharts and Socket.IO. Staff sign in with separate cookies from the player app, and the backend authorizes every call.

```bash
cp .env.example .env.local
npm run dev        # http://localhost:3001
npm run typecheck
npm run lint
npm test
```

Setup for the whole platform is in the root `README.md`.
